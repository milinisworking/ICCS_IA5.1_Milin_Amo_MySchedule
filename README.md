## Purpose

MySchedule(my project's name) is a small schedule manager for students who want to organize classes, assignment deadlines, appointments, and other activities. It should help me see what I have planned for a particular day.

## Requirements

1. The user can add an event with a title, date, start time, and end time.
2. The user can view events for a selected date, with events shown in start-time order.
3. The program must reject invalid dates, end times that are not after start times, and events that overlap with another event on the same date.
